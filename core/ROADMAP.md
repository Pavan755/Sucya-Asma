# Core roadmap

1. Define the minimum shared identifiers and artifact schemas.
2. Implement path, folder-template, and ledger validation helpers.
3. Add ffprobe reports and caption/credit checks.
4. Run all utilities on a still-led pilot episode.
5. Measure failures and revise schemas before introducing agents.
6. Add retrieval/drafting agents with citations and output contracts.
7. Orchestrate only stable stages; preserve approval gates and retry limits.

Do not build a large autonomous system before completing one episode manually. The episode workflow is the source of requirements for the code.
