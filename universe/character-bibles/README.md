# Character library

This folder stores versioned character canon for the Sucya-Asma story universe. Begin with `docs/CHARACTER_WORKFLOW.md` and `templates/character-bible-template.md`.

## Ramayana

- [Rama](ramayana/rama.md) — current bible draft.
- [Rama v1 approved snapshot](ramayana/rama-v1-approved.md) — inspect approval date and reference pack before relying on this status.
- [Rama performance](ramayana/rama-performance.md) and [motion](ramayana/rama-motion.md).
- [Hanuman](ramayana/hanuman.md) — current bible draft.
- `hanuman-v1-approved.md`, `hanuman-performance.md`, and `hanuman-motion.md` — inspect completeness and approval provenance.
- `references/` — visual evaluation and provenance.

## Rules

- Do not overwrite an approved version; create a new version and retain history.
- Cite textual and artistic sources and distinguish them from design choices.
- Track prompt/model/input provenance for every generated reference image.
- Keep identity, performance, motion, and approval documents separately linked.
- Treat approvals as version-specific; an approval file is not proof that missing references or checks were completed.
